# Vela Salon Supply Co. Website

A responsive static website created for a small Johannesburg salon-equipment business.

## Included
- 20 uploaded product images
- Professional responsive design
- Product category filters
- Individual “Order on WhatsApp” buttons
- Contact and physical location section
- Google Maps location button
- No invented product prices

## Important
The WhatsApp number is `0787412314` and the website uses the South African international format `+27 78 741 2314` for WhatsApp links.

## How to use
Open `index.html` in a browser, or upload the whole folder to a static website host.
